API reference

The Render Monitor backend exposes a read-only HTTP API under /api/render plus a health check and a WebSocket log stream. All routes forward to the Render API with your server-side key.

Conventions

  • Base path for application routes: /api/render.
  • All endpoints are GET and return JSON.
  • The /health endpoint is unauthenticated and sits outside the API base.
  • List endpoints return the Render API’s cursor-paginated wrapper arrays.
ℹ

Set BASE=http://localhost:3001 for the examples below when running locally.

Health & connection

Method Path Description
GET /health Liveness probe. Returns immediately with no dependencies.
GET /api/render/connection/status Verifies the API key by probing /services?limit=1. 
curl "$BASE/health"
# {"status":"ok"}

curl "$BASE/api/render/connection/status"
# {"connected":true}

Services

Method Path Query parameters Description
GET /api/render/services limit, cursor, ownerId List services. limit defaults to 100, capped at 100.
GET /api/render/services/:id — Get a single service by ID. 
curl "$BASE/api/render/services?limit=20"

Deployments

Method Path Query parameters Description
GET /api/render/services/:id/deploys limit, cursor, status List deploys for a service. status is comma-separated (e.g. live,build_failed) and is sent as repeated status[i] params.
GET /api/render/deploys/:id serviceId required Get a single deploy. Requires the owning serviceId. 
# Latest deploy for a service
curl "$BASE/api/render/services/srv-abc123/deploys?limit=1"

# Only failed deploys
curl "$BASE/api/render/services/srv-abc123/deploys?status=build_failed,update_failed"

# A single deploy
curl "$BASE/api/render/deploys/dep-xyz789?serviceId=srv-abc123"

Events

Method Path Query parameters Description
GET /api/render/services/:id/events limit, cursor, eventType List events for a service. limit defaults to 20, capped at 100.

Logs

Method Path Description
GET /api/render/logs Query historical logs. resource is required.
GET /api/render/logs/values List available values for a given filter label.
GET /api/render/logs/stream/info Returns guidance for the WebSocket stream endpoint.

/logs query parameters

Name Required Description
resource Yes Comma-separated resource IDs to query.
ownerId No Workspace ID. Defaults to the single workspace on your key.
limit No Defaults to 100, capped at 100.
type No Comma-separated log types (e.g. app,request).
level No Comma-separated levels (e.g. error,warn).
startTime, endTime No ISO 8601 timestamps bounding the query window.
direction No Result ordering direction.
text No Full-text search within messages.
path, statusCode, method, host No Request-log filters.
instance, task, taskRun, sandbox No Instance / task / sandbox filters.

/logs/values query parameters

Name Required Description
resource Yes Comma-separated resource IDs.
label No Label name to enumerate values for.
ownerId No Workspace ID. Resolved automatically when omitted.
startTime, endTime No ISO 8601 time window. 
curl "$BASE/api/render/logs?resource=srv-abc123&level=error&limit=50"
curl "$BASE/api/render/logs/values?resource=srv-abc123&label=level"

All metric endpoints accept the same core parameters.

Method Path Extra parameters
GET /api/render/metrics/cpu instance
GET /api/render/metrics/memory instance
GET /api/render/metrics/http-requests —
GET /api/render/metrics/http-latency quantile (default 0.95)
GET /api/render/metrics/bandwidth —
GET /api/render/metrics/bandwidth-sources —
GET /api/render/metrics/disk-usage —
GET /api/render/metrics/instance-count — 
curl "$BASE/api/render/metrics/cpu?resource=srv-abc123&resolutionSeconds=60"

Responses are arrays of series with labels, values, and a unit.

Workspaces

Method Path Description
GET /api/render/workspaces List Render workspaces (owners) for your key.

Log stream (WebSocket)

Protocol Path Description
WS /api/render/logs/stream Live log stream proxied to Render’s /logs/subscribe.

Pass the same query parameters as /logs on the WebSocket URL. The stream is unidirectional; client messages are ignored. 

const ws = new WebSocket(
  "wss://your-backend.onrender.com/api/render/logs/stream" +
  "?resource=srv-abc123&ownerId=tea-xyz"
);
ws.onmessage = (e) => console.log(JSON.parse(e.data));

The server also emits control messages of type info or error to signal connection state and failures.

Errors

Errors are returned as JSON with an HTTP status code. Render API errors are passed through with their original status and message. 

{
  "message": "Render API error 401: Unauthorized",
  "code": "unauthorized"
}
Status Meaning
400Missing or invalid query parameter (e.g. logs without resource).
401Invalid or missing RENDER_API_KEY.
429Render API rate limit reached.
500Unexpected server error. Stack traces appear only in development.
Render Monitor — internal code name “Render Control Center”.
